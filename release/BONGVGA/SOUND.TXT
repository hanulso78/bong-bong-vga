  봉봉 한글판 - 사운드블래스터 / 애드립 맞추기          (BONGVGA.EXE)
============================================================================

[먼저 알아 둘 것]

  이 게임이 쓰는 소리 장치는 두 가지뿐입니다.

    1) PC 스피커   - 걸음·먹기·죽기 같은 효과음.  아무 기계에서나 납니다.
    2) OPL2 (FM)   - 배경 음악 세 곡.  애드립이나 사운드블래스터가 필요합니다.

  음악은 포트 388h(주소) / 389h(자료) 에 직접 쓰는 방식입니다.
  디지털 소리(DMA)는 쓰지 않으므로

    - IRQ / DMA 를 맞출 것이 없습니다
    - SET BLASTER 를 안 해도 됩니다
    - 소리 드라이버를 올릴 것이 없습니다

  애드립이 없으면 음악만 안 나오고 게임은 그대로 돌아갑니다
  (첫 화면에서는 예전처럼 PC 스피커 멜로디가 나옵니다).

  나오는 곡
    첫 화면     BB00.VGM    4.3초
    게임 중     BB01.VGM   55초, 끝없이 되풀이
    판 깼을 때  BB02.VGM    3.6초
    게임 끝     BB03.VGM   10.5초
    다 깼을 때  BB04.VGM   15.5초
    떨어질 때   BB05.VGM    1.7초 ("삐이익~")
    최고 기록   BB06.VGM   17초, 끝없이 되풀이
    이어하기    BB07.VGM   10초, 끝없이 되풀이

  이 곡들은 SOUND.DAT 한 파일에 묶여 있습니다.
  SOUND.DAT 가 BONGVGA.EXE 와 같은 폴더에 있어야 합니다.


[1] 도스박스 (DOSBox)

  dosbox.conf 의 [sblaster] 칸을 보고 아래처럼 되어 있으면 됩니다.
  대부분 처음 그대로 두어도 소리가 납니다.

      [sblaster]
      sbtype=sb16
      oplmode=auto
      oplemu=default
      oplrate=44100

  sbtype=none 으로 두면 OPL 도 같이 꺼지는 판이 있습니다.  음악이 안 나면
  sbtype 을 sb16 으로 되돌려 보세요.

  소리가 작으면

      [mixer]
      master=100
      fm=100

  도스박스-X (DOSBox-X) 도 칸 이름이 같습니다.  더 옛날 소리를 원하면
  sbtype=sb1 / oplmode=opl2 로 두면 OPL2 그대로가 됩니다.


[2] 진짜 기계 - ISA 사운드블래스터 / 애드립

  OPL 의 주소 388h 는 모든 카드가 똑같이 쓰는 자리라 따로 맞출 것이 없습니다.
  카드가 꽂혀 있고 소리가 나는 상태면 그것으로 끝입니다.

  다만 아래 두 가지는 확인해 보세요.

  (가) PnP 카드 (SB16 PnP, AWE32/64, ESS 등)
       전원을 켠 뒤 초기화 프로그램을 한 번 돌려야 소리 장치가 깨어납니다.
       CTCM/CTCU (크리에이티브) 나 UNISOUND 같은 것을 AUTOEXEC.BAT 에
       넣어 두면 됩니다.  예)

           CTCM
           SET BLASTER=A220 I5 D1 H5 P330 T6

       (이 게임은 BLASTER 를 읽지 않지만, 초기화 프로그램들이 봅니다)

  (나) FM 음량이 0 으로 내려가 있는 경우
       SB16 이후 카드는 전원을 켤 때 FM 음량이 0 인 일이 있습니다.
       크리에이티브의 SB16SET / MIXERSET 이나 도스용 믹서로 FM(신디사이저)
       음량을 올려 주세요.  예)

           SB16SET /M:15 /VOC:15 /MIDI:15

  옛날 애드립 카드(OPL2)와 사운드블래스터 1.0/2.0 은 아무것도 안 해도 됩니다.


[3] 86Box / PCem 같은 기계 흉내 프로그램

  소리 카드를 "Adlib" 이나 "Sound Blaster 1.5/2.0/Pro/16" 중 아무것이나
  골라 두면 됩니다.  OPL 주소는 건드릴 필요 없습니다.


[4] 소리가 안 날 때

  ( ) SOUND.DAT 가 EXE 와 같은 폴더에 있습니까
  ( ) 게임 안에서 S 키를 눌러 소리를 꺼 두지 않았습니까
      (S 는 켜기/끄기 스위치입니다.  효과음과 음악이 같이 꺼집니다)
  ( ) 도스박스라면 sbtype 이 none 으로 되어 있지 않습니까
  ( ) 진짜 기계라면 FM 음량이 0 이 아닙니까
  ( ) 다른 프로그램이 카드를 잡고 있지 않습니까

  효과음(PC 스피커)은 나는데 음악만 안 난다면 애드립을 못 찾은 것입니다.
  게임은 시작할 때 OPL 의 타이머를 한 번 돌려 보고, 상태 비트가 바뀌지
  않으면 애드립이 없다고 봅니다.


[5] 만든 쪽 이야기

  VGM 은 "몇 번째 샘플에 어느 레지스터에 무엇을 써라" 를 적어 둔 기록입니다.
  이 게임은 그 기록을 그대로 388h/389h 에 흘려보냅니다.  레지스터를 쓴 뒤에는
  상태 포트를 여러 번 읽어 OPL2 가 요구하는 3.3us / 23us 를 채웁니다 -
  기계가 아무리 빨라도 박자가 맞습니다.
  음악은 게임을 멈추지 않습니다.  화면을 한 장 그릴 때마다 "때가 된 명령"
  만 처리하고 지나갑니다.
