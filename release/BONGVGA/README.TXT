봉봉 (BONG BONG) - 한글 개선판

  1989년 원판을 C 로 옮긴 뒤, 요즘 보기 편하도록 손본 것입니다.

    - VGA 모드 13h, 입체 음영을 넣은 그림
    - 16픽셀씩 끊기지 않는 부드러운 움직임
    - 한글 표시
    - 스테이지 20개 (11~20판은 새로 만든 것, 먹이도 10가지 새로 그렸습니다)
    - 최고 점수표 (BONG.HI 파일로 남습니다)
    - 멈춤 / 소리 끄기 / 이어하기
    - 시범 플레이 (타이틀에서 가만 두면 돌고, D 를 누르면 1판부터 끝까지)
    - 기계가 빨라도 같은 속도
    - 애드립 곡 (애드립/사운드블래스터가 있을 때)
      여덟 곡 - 첫 화면 / 게임 중 / 판 깼을 때 / 게임 끝 / 다 깼을 때 /
      떨어질 때 / 최고 기록 / 이어하기 (SOUND.DAT 에 묶여 있습니다)

조작
  화살표   움직이기        스페이스 뛰기
  P        멈춤            S        소리 끄기
  D        시범 보기       Esc      끝내기

실행
  DOSBox 나 도스에서 이 폴더로 가서  BONGVGA  라고 칩니다.

이 폴더의 파일
  BONGVGA.EXE    게임
  CWSDPMI.EXE    도스에서 32비트로 돌리기 위한 DPMI 서버 (같이 있어야 합니다)
  16X16.DAT      스프라이트 42장 (1989년 원본 파일)
  16X16B.DAT     11~20판에 쓰는 새 먹이 10가지
  B_ST.DAT       스테이지 자료 (20판)
  SOUND.DAT      애드립(OPL2) 곡 여덟 개를 묶어 둔 것
                 (첫 화면 / 게임 중 / 판 깼을 때 / 게임 끝 /
                  다 깼을 때 / 떨어질 때 / 최고 기록 / 이어하기)
  HSMALL.FNT     한글 글꼴
  ESMALL.FNT     영문 글꼴
  (BONG.HI 는 최고 점수를 저장할 때 게임이 스스로 만듭니다)
